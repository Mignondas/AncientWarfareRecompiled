# AncientWarfareRecompiled

Portage de [Ancient Warfare 2](https://github.com/P3pp3rF1y/AncientWarfare2) (Minecraft 1.12.x, Forge)
vers **Minecraft 1.21.1** et **NeoForge**.

## État

Phase 0 : squelette de projet compilable, sans contenu de jeu.

Les modules suivent l'ordre de portage prévu : Core, Structure, Automation, NPC, Vehicles.
